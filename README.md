# GitHub 学习练习仓库

这是一个用于学习和练习 GitHub 基础操作的仓库，主要用于熟悉以下内容：

- 仓库的创建与管理
- 分支（Branches）的创建与合并
- Pull Request（拉取请求）的完整流程
- Issues（议题）与 Projects（项目面板）的使用
- Git 本地与远程的协作工作流

## 项目结构
- ├── README.md # 项目说明文档
- ├── index.html # 示例网页文件
- └── .gitignore # Git 忽略文件配置（如需）

## 学习记录

- ✅ 创建仓库
- ✅ 克隆到本地（VS Code）
- ✅ 创建分支（test-branch、test2）
- ✅ 提交修改并推送
- ✅ 创建并合并 Pull Request
- ✅ 创建 Release / Tag
- ✅ 管理 Issues 和 Projects

## 环境要求

- Git（已安装）
- GitHub 账号
- VS Code（或其他代码编辑器，可选）

## 如何开始

- 1.克隆此仓库：
   ```bash
   git clone https://github.com/你的用户名/仓库名.git
   ```
- 2.进入目录：
   cd 仓库名
- 3.查看分支或切换分支：
   git branch
   git checkout 分支名
